# 户外体验站实现与验证

实现遵循 [体验站设计](agent-experience-design.md)。当前代码提供动画首页、户外聊天界面、侧栏个人入口、96 款人民币装备、匿名历史与长期记忆、旧目录兼容及一条命令部署。

用户已确认当前版本测试通过。侧栏个人资料更新的本地验证为 TypeScript 编译检查，通过后由用户体验验收。以下保留各项已有检查及其范围；用户反馈不改写全量自动化检查的记录。文档整理不新增、修改或重跑测试。

## 行为覆盖

| 需求 | 实现与证据 | 边界 |
|---|---|---|
| 动画首页 | `/` 使用原创 SVG 山野场景，点击进入 `/chat`；浏览器确认首页没有身份或 API 请求，减少动态效果设置生效 | 不生成商品照片 |
| 历史与购物车布局 | 左侧历史栏可折叠并保存状态；手机历史弹窗、右下角圆形购物车与右侧抽屉可操作；Escape、遮罩关闭和焦点返回有效 | 使用本地身份与 API 夹具 |
| 侧栏个人入口 | 头像与昵称入口提供个人资料、使用说明、关于体验；支持昵称编辑和四款户外头像，TypeScript 编译通过，用户确认更新后测试通过 | 展示资料按现有匿名身份保存在当前浏览器，不写入 Supabase 或模型记忆 |
| 字体与响应式布局 | 正文、卡片和控件放大，宽聊天区；320、390、768、1440 px 视口没有页面横向溢出，输入框按宽度和内容调整高度，购物车按钮避开输入框 | 手机检查为 Chrome 设备模拟 |
| 户外商品与推荐依据 | 8 类、96 个主商品、120 个尺码变体；规格、限制、模拟评价与价格固化；中文帐篷检索、重量、容量、舒适温度筛选经离线调用核对 | 真实模型的选型与追问效果需线上体验 |
| 人民币与旧目录 | 新商品、卡片和购物车使用 CNY；旧商品不参与搜索；浏览器确认旧购物车仍显示 US$149.00，数量和结算禁用，移除与查看保留 | 本地未执行真实 PostgreSQL 事务检查 |
| 金额与配送 | 对比不计算跨币种差价，计划注明每步一件的参考口径；匹配当前购物车时配送使用实际数量，229 元的两件商品按 458 元判断免运费 | 结算不下单、不扣款 |
| 匿名身份与历史 | 保留身份键，`outdoor-v1` 仅区分选中的对话；旧历史仍可访问，当前户外入口首次创建空对话；历史和最终卡片可恢复 | 本地证据不覆盖真实多访客隔离与重启恢复 |
| 短期与长期记忆 | 沿用工作上下文预算、完整历史归档、按用户保存偏好及后台重试；户外提示词静默使用相关偏好，临时行程留在对话内 | 本次未调用真实聊天、摘要或记忆模型 |
| 一条命令部署 | `scripts/deploy.sh` 顺序构建、只读检查币种列、停止旧 API 并更新容器；模拟流程确认构建或迁移检查失败时不进入服务切换 | 本地没有 Docker，未在本地执行真实容器部署；SQL 迁移仍单独执行一次 |

## 部署验收

常规更新使用 `git pull --ff-only origin main && bash scripts/deploy.sh`，沿用现有 `.env`。侧栏个人资料更新无需新增迁移。首次从旧商品版本升级且未完成 `002` 时，按 [户外版本升级](deployment.md#户外版本升级) 操作；已有迁移不重复执行，商品 JSON 随源码更新。

真实环境专项验收范围见 [部署验收](deployment.md#部署验收)，包括购物车币种、历史、匿名隔离、长期偏好、长对话、断流和重启恢复。用户确认当前体验测试通过；真实数据库事务检查仍与页面体验验收分开记录。沿用线上 Supabase 项目时，不同时启动本地和线上 API。数据库事务检查只能使用 [独立测试项目](../supabase/README.md#transaction-verification)。
