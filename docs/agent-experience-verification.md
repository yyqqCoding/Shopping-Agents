# 中文体验站实现与验证

实现遵循 [体验站设计](agent-experience-design.md)。中文页面、匿名身份接入、对话持久化、长对话整理、长期记忆存储和部署配置已完成代码接入。当前证据来自本地测试与生产构建，尚未建立真实 Supabase、模型及域名的完整验收结果。

## 行为覆盖

| 需求 | 实现与证据 | 验证状态 |
|---|---|---|
| 中文界面与商品内容 | 中文页面、卡片、错误和工具进度；87 个主商品、21 个变体、11 个分类及固化详情、政策、价格和评价依据；中文查询、结构化筛选与数据校验测试 | 本地通过；真实 Agent 回复仍需体验验证 |
| 无登录页的匿名访问 | `identity.ts` 恢复凭证并协调多标签页；API 从 Supabase Auth 获取真实归属；Node、API 与浏览器测试覆盖恢复、失败、独立访客及越权访问 | 自动化通过；用户确认开启匿名访问后本地体验正常，完整真实身份隔离验收仍待执行 |
| 会话隔离与历史恢复 | 会话分别保存上下文、来源记录和购物车；完成事件在存储提交后发送；刷新读取保存的文字和卡片；重复请求复用原结果 | 接口与浏览器测试通过；真实数据库事务和重启恢复待验证 |
| 短期记忆与长对话 | 调用前检查 UTF-8 预算，摘要较早完整回合，保留近期工具配对；失败保留原快照；完整原始历史不随工作上下文压缩而改写 | 自动化通过；真实模型的长对话效果待验证 |
| 跨对话长期记忆 | 按用户读取偏好；提取失败不阻断聊天；来源顺序、清空版本和删除标记阻止旧任务写回；当前需求优先，临时购物条件不自动转为长期偏好 | 存储接口、规则和故障路径测试通过；数据库事务及模型提取语义待联调 |
| 隐藏记忆实现细节 | 移除前台记忆面板及状态展示，过滤记忆工具进度，提示词和技能要求普通保存保持静默 | 规则、事件和页面测试通过；真实模型措辞待体验验证 |
| 域名访问与单实例部署 | API、Web 和 Caddy 配置提供同源 HTTPS 与 SSE，API 限定一个 worker，配置匿名访问频率及模型额度 | 生产构建通过；Docker、HTTPS 及真实服务连接尚未验证 |
| 商品图片 | 保留 9 张现有照片、缺图占位和生成提示清单 | 按用户要求暂缓生成；99 个主商品或变体图片引用待补 |

模型替身会按场景返回预设内容。它能验证上下文装配、存储调用、重试及页面行为，不能证明真实模型能够稳定提取偏好、遵守所有措辞要求或完成推荐。

Python 检查使用现有 Windows Python 3.11 环境，Node 测试使用 Linux Node 22.21.1。当前 `node_modules` 包含 Windows 原生依赖，统一 `verify_all.py` 的 Linux Web 构建步骤失败；普通与 standalone 构建随后在 Windows Node 20.17.0 下分别通过。因此未将该混合环境的统一命令记为全程通过。部署目标仍为 Node 22，Docker 构建需要在部署环境确认。

浏览器脚本使用真实生产页面及本地身份、API 夹具，不连接 Supabase 或模型。执行方法见 [examples 验证](../examples/README.md#验证)。数据库测试入口及隔离要求见 [事务验证](../supabase/README.md#transaction-verification)。

测试契约之外补充了外部失败与并发边界：受理请求结果不确定时不启动工具、提交失败持续重试存储、后台任务租约过期、模型完成事件之后发生异常，以及损坏凭证不自动替换身份。这些用例保护现有的数据完整性与恢复约定，没有增加产品流程。

## 真实环境待验收

Supabase 项目已配置，实际接口检查确认本地 API、前端代理和会话表读取可用；用户确认开启匿名访问后本地体验正常。这些结果尚未覆盖完整数据库事务契约、真实记忆提取和长对话场景。

目标服务器为 Ubuntu 22.04 x86_64，Docker Compose 可用，80/443 未被占用。Docker 镜像构建、服务器运行资源及 HTTPS 访问仍需按 [部署说明](deployment.md#中文体验站) 验证；数据库事务测试必须使用独立测试项目。

配置后的验收以 [部署验收](deployment.md#部署验收) 为准，包含两个身份的数据隔离、偏好提取成功后的跨对话推荐、流式断连恢复以及 API 重启后的历史与购物车恢复。健康检查和本地模拟测试均不能代替这些结果。
