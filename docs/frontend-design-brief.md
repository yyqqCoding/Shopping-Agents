# 户外前端设计约定

## Direction contract

THESIS: 从一段行程到一份装备清单。首页呈现场景与取舍，助手承担选择与确认。

OWN-WORLD: 深松绿、岩石白、路标黄。自托管中文衬线标题、清晰的无衬线界面、原创场景摄影和浅底商品摄影。

STORY: 山野首屏、出行场景、行程到清单的滚动演示、精选装备、参数对照、行程输入。商品目录和详情提供独立浏览入口。

FIRST VIEWPORT: 全幅山谷摄影，左侧大型中文标题与行程入口，下沿探索提示；导航固定在顶部。

FORM: 用户确认的山野现场与装备桌方向优先于随机方案。Impeccable 概念参考键为 32eaecb6。桌面装备桌随章节变化，手机按自然阅读顺序展示。

FINISH: 全部商品图片入库，页面与部署依赖提交，CI 移除。用户明确要求不运行任何测试，并在服务器部署后自行验收；本次不执行技能默认的测试、构建或浏览器评审流程。
