# 对话响应速度优化

## 范围

优化从发送消息到文字、卡片可见的链路，保留现有聊天界面、服务端校验、工具权限和持久化语义。沿用 SSE，不增加 WebSocket。后台记忆提取、会话笔记和 Dream 继续独立运行，非流式调用不等于前台回复被阻塞。

## 已确认的等待

- `web-shared/turn.ts` 将收到的完整列表重新拆成逐条预览，每步等待 180ms；最终卡片还可能排在预览队列后，间隔 80ms。
- `EagerDispatcher` 已并行执行工具，但运行时在模型整轮结束后等待 `gather`，再一次发送所有工具的展示事件。先完成的卡片被较慢的工具或模型后续生成阻塞。
- 每个文字增量都会更新整段聊天状态，`Transcript` 同时重新遍历和渲染历史文字、卡片；聊天组件的内联回调还使组件缓存失效。
- SSE 解析按网络分块读取，没有等待完整回复；Caddy 已设置 `flush_interval -1`，API 已关闭代理缓冲。当前证据不支持更换传输协议。
- 没有模型输出时，API 首个字节直到 15 秒心跳才发出；生产前端代理下浏览器实测连接确认为 15094ms。建立流时立即发一个 SSE 注释帧，提前刷新响应头；不把注释显示成用户内容。

## 实现

1. 完成的工具通过同一 SSE 连接即时发送经过服务端校验的展示事件。在模型继续生成、其他工具仍运行时也能展示。模型上下文中的工具结果仍按调用顺序组装，每个工具只执行一次、展示完成事件只发一次。取消时关闭流读取任务和工具任务。
2. 删除前端人为逐条播放队列。预览直接采用最新版本，最终卡片立即替换预览。未经最终校验的卡片继续禁用操作，断流时不保留未完成卡片。
3. 将同一动画帧内的聊天变更合并提交；结束、错误和会话切换时正确刷新或丢弃积压。后台标签页使用有界计时兜底。缓存不变的历史消息和卡片，稳定渲染回调。
4. 在浏览器追踪里记录连接建立、首文字、首卡片和总耗时；服务端记录预处理和模型首文字耗时。只记录时长与匿名会话标签，不记录用户正文。通过同一请求的分段耗时区分模型等待与展示延迟。

浏览器 Performance 面板使用 `shopping:chat:connected`、`shopping:chat:first-text`、`shopping:chat:first-card`、`shopping:chat:complete`。这些是内容到达 JavaScript 的时间，不冒充浏览器绘制时间；每次发送清理上一轮同名 measure，避免累计。主对话 trace 同时保留分段时长。工具 trace 以调用 ID 配对，支持同名工具乱序完成。

聊天框架限制溢出传播，只有消息区承担历史滚动。人工验证发现长对比表会让外层隐藏容器可滚动，输入框聚焦后外层偏移 308px 并裁掉标题栏；在 `.workspace-main` 使用 `overflow: clip`，阻止子内容扩张外层滚动范围。

## 验证

不新增测试文件，不执行全量测试。使用临时脚本验证工具提前完成、乱序完成、取消与重复事件；构建前端并进行浏览器人工验证。用实际模型确认文字和卡片正常流出；记录实际测量，模型速度波动不作为前端收益。无法确认的部署网络效果单独说明。

## 验证结果

| 项目 | 结果与口径 |
|---|---|
| 工具提前展示 | 同一受控流、相同 30ms/300ms 工具延迟和 400ms 后续模型等待，旧实现首卡 406ms，新实现首卡 32ms；慢工具 313ms 展示，模型文字 407ms 到达。这是受控调度验证，不是实际模型提速比例 |
| 工具一致性 | 人工验证重复完成事件不发送、工具只执行一次、关闭 eager 后仍并行完成、展示按完成顺序而模型结果按调用顺序、坏 JSON 返回错误结果、取消后读取任务与工具任务结束 |
| 生产前端 SSE 连接 | 同一 localhost → Next 生产服务 → API 链路，没有注释帧时连接确认为 15094ms，增加注释帧后为 70ms。注释不出现在回复与历史中 |
| 真实模型 | `deepseek-ai/deepseek-v4-flash` 完成水壶选品、对比卡片及后续两次文字回复，刷新后恢复 3 轮历史及最终卡片；真实请求不依赖受控模型替身 |
| 等待归因 | 选品首轮准备 31ms、模型调用 11875ms；后续文字请求首字 33448ms、完成 34035ms。即时握手后的短回复连接 70ms、首字 14064ms、完成 14373ms；对应服务端准备 16ms、模型首字 13968ms。不能把不同请求之间的模型耗时差当成前端收益 |
| 静态检查 | Python Ruff 检查、格式检查与编译通过；Next 生产构建与 TypeScript 检查通过；界面机械扫描无报告 |
| 聊天框架 | 长历史恢复并聚焦输入框后，外层 scrollTop 为 0、scrollHeight/clientHeight 均为 720px、标题栏 top 为 0；1280px 视口无页面横向溢出 |

本次未新增或修改测试文件，未运行 pytest 或全量验证。页面使用临时本地数据目录与 JSON 商品夹具，模型使用已配置的真实网关。未测公网代理、弱网设备或线上用户分位数，未声称 LCP/INP 或整体响应时间改善比例。网关仍返回流式 `output_tokens=0`，无法据此验证输出 token 计费；后台记忆/会话笔记的非流式请求保留，后台出现的网关重试与前台流式展示分别处理。
