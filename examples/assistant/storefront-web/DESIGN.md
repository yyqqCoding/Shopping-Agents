# 户外装备助手界面

## 首页

`app/page.tsx` 从公开目录读取展示商品。`components/landing/LandingPage.tsx` 拥有首页导航、章节与页尾；`app/landing.css` 的 `.field-home` 作用域隔离其视觉，不修改目录和聊天的共享样式。

米白 `#f2f0e9` 是首页画布，炭墨 `#272822` 是主文字，`#66665c` 是辅助文字，安全橙 `#c44925` 标记行动。睡眠与照明章节使用炭墨夜色和米白文字，橙色调亮以保持对比。全页不用大面积森林绿、玻璃导航、照片白边或清单演示。

首屏以大型闭合背包为中心，中文“向山野 / 再出发。”分列两侧。品牌和开始准备入口位于顶部两侧。首屏不提供输入框、清单或自动场景切换。背包和章节商品使用真实透明 PNG。饮水和炊具使用原创满幅场景摄影，不使用矩形照片卡片。来源和原始提示词在 `data/landing-image-prompts.json` 与 `data/unpack-image-prompts.json`。

章节顺序是背包主视觉、饮水、睡眠、照明、炊具和行动入口。每章占据完整视口，有独立的场景标题、商品构图与环境线索：饮水是水壶向杯中倒水的近景，睡眠是月色中的睡袋，照明是头灯投出的斜向光束，炊具是盛着热汤的露营餐桌。场景摄影仅表达使用环境；商品、价格与参数仍来自目录，不使用图片尺寸暗示精确产品比例，不添加实测或认证承诺。

`public/images/landing/water-scene.png` 与 `cook-scene.png` 是用户提供的原创场景原图，同名 WebP 是页面使用的压缩副本。饮水背景提前以低优先级加载，炊具背景延迟加载，文字区和导航区通过浅色遮罩保持对比。摄影章节的标题、五件商品选择栏和参数价格位于左侧，右侧保留完整倒水和用餐主体。睡眠和照明章节使用原有透明商品展台构图。

章节左下始终显示当前商品名称、两项参数、人民币价格和详情链接，悬停或键盘聚焦其他商品后保留该选择。睡垫显示 R 值，睡袋显示舒适温度，头灯显示最高亮度，炊具按商品显示容量、功率或组成。顶部导航可直接跳到任一章节，底部提供章节进度和下一章入口。光束跟随照明章节内的指针缓慢转动。

中文展示字体沿用自托管 `public/fonts/field-display.otf`。首页标题随视口缩放；导航和图片说明保持较小尺度。图片区无统一圆角卡框。商品列表使用原有目录摄影，名称和价格置于图外。

## 首页动效与交互

`components/landing/motion/useUnpackMotion.ts` 使用 GSAP 和 ScrollTrigger，保留原生滚动。桌面前半页固定一个视口，使用一条可逆时间线。闭合背包随滚动缩小、轻微向左上方移动并淡出，视线转入饮水场景，标题和商品接续入场。摄影章节的商品选择栏轻微上移，睡袋舒缓落位，照明通过横向揭幕进入。每章提供五件商品，信息分段显现。章节链接按时间线实际时长定位到商品落定的位置。

背包作为前景位于饮水背景上方，风景从滚动初段开始整幅显现。转场底层始终保留完整背景，后续章节通过裁切覆盖上一章；退场仅作用于前景内容，反向滚动会重新露出上一章完整场景。背景随滚动轻微缩放。离开固定画面后进入行动页尾。

饮水照片叠加沿水流移动的反光和杯口细涟漪，炊具照片叠加锅口缓慢升起的蒸汽。照片与效果使用一致的原图比例和居中裁切，并在同一容器内轻微移动。睡眠章节有月光明暗、错开的星光、偶尔划过的流星和睡袋呼吸浮动，文字与商品说明保持稳定。蒸汽柔化限制在锅口局部，不对整张照片持续模糊。

入场、指针、自动浮动和滚动各有独立变换容器。首屏背包保留轻微的指针倾斜，滚动过渡后完全退场。商品落定后保留轻微悬停反馈，睡袋在悬停或键盘聚焦时暂停浮动。非当前章节使用 inert 避免隐形链接抢占交互。

环境动画仅在当前章节可见且浏览器标签页处于前台时播放。章节底部的动效按钮暂停或恢复环境动画和指针反馈，手动滚动仍可切换章节。`gsap.matchMedia` 监听减少动态效果偏好，退出时回收效果。无脚本和减少动态效果时内容保持可见，环境动画与动效按钮停用。图片保留明确尺寸，首屏优先加载，其他图片按需加载。链接保留可见键盘焦点和跳到正文入口。

场景链接由 `lib/navigation.ts` 写入聊天草稿，只有显式发送才调用助手。商品链接进入已有详情页。首页导航和页尾都提供装备目录与聊天入口。

## 目录与聊天

`app/globals.css`、`app/design.css` 和 `app/redesign.css` 保持目录、详情和聊天的共享基础。它们沿用浅色画布、松墨文字、纸面卡片与已有交互。`SiteChrome.tsx` 提供这些公开页面的导航和页尾。

推荐卡显示商品、推荐理由、规格和显式操作；多规格商品交由助手确认。比较使用可访问表格，不根据文案位置推断属性。购物车反馈仅在服务端确认后展示。对话身份、目录接口和购物车写入不属于首页视觉逻辑。

## 验证与交付

首页以桌面为目标，不开展手机版适配。本轮不运行测试或浏览器验收，由用户在本地查看效果。部署由用户执行。

首页细节：移除章节底部装饰短句、悬停操作提示和场景旁注，保留商品事实与动效控制。使用原生鼠标，不添加跟随装饰。主行动使用实色按钮，商品详情使用细边框按钮，下一章入口配小型圆形箭头，辅助链接使用轻底色反馈。页尾行动箭头采用细描边，悬停填橙色。页尾上方与底部无分割边框，摄影底部完全淡入米白。按钮保留键盘焦点与按下反馈，暂停控制使用 aria-pressed。

## 背包装载透视

`components/landing/BackpackReveal.tsx` 拥有首屏局部剖视。默认展示带侧袋水壶与双绑带泡沫垫的背包，主包腔内下层是压缩睡袋，中层是套叠炊具和食物，上层是收纳衣物与头灯。这是示意装载，不作为容量或商品组合承诺。指针划过顶袋、主包腔和可见侧面后显现真实颜色内部；顶袋增加急救包与折叠地图，侧面展示同一组装载的深度。`motion/backpackWater.ts` 以局部 WebGL 波场推动透视边缘和纹理折射，轨迹约 2100 毫秒内收回，不绘制鼠标圆环；空闲时停止渲染。WebGL 不可用时退回软边揭开。外挂、水壶、绑带与垫子始终来自同一外观层。两层画面在同一 Canvas 中使用同一坐标，共享既有背包倾斜与滚动变换。外观纹理预先按连通区域去除纸色背景，保留包体中的浅色细节；1000 像素 WebP 与内部纹理在首屏预加载，浏览器不再执行逐像素抠图。静态背包与 Canvas 共用外观资源；内部纹理失败时保留静态背包。章节商品使用 1024 像素以内的 WebP 压缩副本，由 Next Image 按显示尺寸提供响应式图片，原始 PNG 保留。暂停、离屏、滚动和失焦清除轨迹；减少动态效果时使用点击或键盘静态查看。

首屏水纹：`HeroWater.tsx` 在整个首屏接收鼠标轨迹，低分辨率波场生成明暗余波和位移图，大标题与等高线只在经过位置折射。导航及辅助小字保持清晰，背包保留独立透视。轨迹约 2.3 秒消散；滚动、暂停、失焦或减少动态效果时清除并停止。

首页文案保持精简：首屏只保留向下箭头及无障碍名称，删除四章介绍段落与页尾引导短句；保留标题、商品名称、用途标签、参数、价格及操作文字。
