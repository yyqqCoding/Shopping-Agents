# 户外装备助手界面

## 首页

`app/page.tsx` 从公开目录读取展示商品。`components/landing/LandingPage.tsx` 拥有首页导航、章节与页尾；`app/landing.css` 的 `.field-home` 作用域隔离其视觉，不修改目录和聊天的共享样式。

米白 `#f2f0e9` 是连续画布，炭墨 `#272822` 是主文字，`#66665c` 是辅助文字，安全橙 `#c44925` 标记行动。炭黑只用于按钮、导航和页尾行动入口。全页不用大面积森林绿、玻璃导航、照片白边或清单演示。

首屏以大型背包为中心，中文“向山野 / 再出发。”分列两侧；桌面滚动演出开始后，闭合背包切换为同角度的开口背包。品牌和开始准备入口位于顶部两侧。首屏不提供输入框、清单或自动场景切换。背包和章节商品使用真实透明 PNG，首页不再使用风景矩形图或卡片墙。来源和原始提示词在 `data/landing-image-prompts.json` 与 `data/unpack-image-prompts.json`。

章节顺序是背包主视觉、饮水、睡眠、照明、炊具和行动入口。每个类别占据一个完整视口，以一个主商品和多个变体形成视觉层级；类别标题保持克制，指针悬停或键盘聚焦商品时，标题位置切换为产品名和两项关键参数。商品名与价格来自目录。对比不使用图片尺寸暗示精确产品比例，不添加实测或认证承诺。

中文展示字体沿用自托管 `public/fonts/field-display.otf`。首页标题随视口缩放；导航和图片说明保持较小尺度。图片区无统一圆角卡框。商品列表使用原有目录摄影，名称和价格置于图外。

## 首页动效与交互

`components/landing/motion/useUnpackMotion.ts` 使用 GSAP 和 ScrollTrigger，保留原生滚动。桌面前半页固定一个视口，使用一条可逆时间线。背包旋转靠近镜头，切换为同角度的开口照片；每个类别的三件变体从包口沿不同弧线夸张抬起，主商品回弹落位，信息随后分段显现。类别离开时淡出，下一类别接力进入，滚动离开固定画面后进入行动页尾。

入场、指针、自动浮动和滚动各有独立变换容器。首屏背包只保留轻微的指针倾斜，避免旋转干扰阅读；离开首屏后背包外壳退场，商品变体接力占据画面。取出动作遵循包口遮挡：同类变体先后从背包位置沿弧线加速后减速并回弹，信息层从标题位置展开；落定后保留轻微悬停反馈，避免卡片被甩出。不可见章节使用 inert 避免隐形链接抢占交互。开口背包仅用于首页过渡，不会残留到分类画面。

`gsap.matchMedia` 监听尺寸和减少动态效果偏好，退出时回收效果。无脚本和减少动态效果时内容保持可见。图片保留明确尺寸，首屏优先加载，其他图片按需加载。链接保留可见键盘焦点和跳到正文入口。

场景链接由 `lib/navigation.ts` 写入聊天草稿，只有显式发送才调用助手。商品链接进入已有详情页。首页导航和页尾都提供装备目录与聊天入口。

## 目录与聊天

`app/globals.css`、`app/design.css` 和 `app/redesign.css` 保持目录、详情和聊天的共享基础。它们沿用浅色画布、松墨文字、纸面卡片与已有交互。`SiteChrome.tsx` 提供这些公开页面的导航和页尾。

推荐卡显示商品、推荐理由、规格和显式操作；多规格商品交由助手确认。比较使用可访问表格，不根据文案位置推断属性。购物车反馈仅在服务端确认后展示。对话身份、目录接口和购物车写入不属于首页视觉逻辑。

## 验证与交付

首页以桌面为目标，不开展手机版适配。本轮不运行测试或浏览器验收，由用户在本地查看效果。部署由用户执行。
