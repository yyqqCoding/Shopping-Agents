# 户外装备助手

## Platform
Web. Next.js App Router, React, TypeScript and Tailwind CSS. Desktop is the design target. Existing narrow-screen behavior remains, but mobile compatibility and review are outside the requested scope.

## Product
Chinese-speaking visitors plan hiking and camping equipment through one conversational agent. The public catalog contains 96 fictional unbranded outdoor products and size variants, priced in CNY. Visitors browse equipment, compare specifications and assemble a trip list. Anonymous identities own conversations and carts. Checkout is a simulation and charges nothing.

## Boundaries
The redesign covers the scrolling welcome page, equipment browsing and detail routes, conversation interface and presentation components. Preserve backend APIs, conversation ownership, server-validated tools and cart writes. Images are original generated assets. No invented testimonials, locations, brands, weather services or performance claims. The user authorizes substantial visual reconstruction, prominent homepage animation, frosted glass and soft corners, and delegates remaining design choices. Do not run tests or add CI. The user will deploy and inspect the result on their server.
